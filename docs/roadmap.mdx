# Android Master to Architect roadmap

<span className="badge-complete">● Completed lesson</span> &nbsp; ○ Planned lesson

This roadmap shows the complete learning path. A completed lesson is clickable. Planned lessons will become clickable after their full content is written.

## Part I — Kotlin and Java foundations

- <span className="badge-complete">●</span> [Why Kotlin instead of Java?](./kotlin/why-kotlin)
- <span className="badge-complete">●</span> [Types, variables, expressions, control flow, equality, and smart casts](./kotlin/types-and-control-flow)
- <span className="badge-complete">●</span> [Null safety](./kotlin/null-safety)
- ○ Functions, lambdas, higher-order functions, inline functions, and reified types
- ○ Constructors, `init`, properties, inheritance, interfaces, objects, data classes, enums, and sealed types
- <span className="badge-complete">●</span> [Value classes](./kotlin/value-classes)
- ○ Collections, sequences, generics, variance, extensions, delegates, and DSLs
- ○ Coroutines, structured concurrency, Flow, StateFlow, SharedFlow, and channels
- ○ Java interoperability and gradual migration

## Part II — Android platform and build system

How Android runs apps: processes, ART, Binder, application components, activities, tasks, fragments, resources, Gradle, Android Gradle Plugin, build variants, R8, and build performance.

## Part III — User-interface engineering

Views and XML, rendering, RecyclerView, Compose from fundamentals to internals, state management, accessibility, localization, tablets, foldables, and adaptive layouts.

## Part IV — Architecture and large applications

MVC, MVP, MVVM, MVI, Clean Architecture, SOLID, design patterns, ViewModel, SavedStateHandle, Hilt, Dagger, navigation, modularization, and enterprise-scale decisions.

## Part V — Data, networking, and offline-first design

SQLite, Room, DataStore, storage, repositories, use cases, Retrofit, OkHttp, serialization, offline synchronization, conflict resolution, and Paging 3.

## Part VI — Background work and device features

WorkManager, services, alarms, notifications, permissions, location, maps, BLE, NFC, sensors, camera, media, files, and relevant Firebase services.

## Parts VII–X — Production engineering and architect practice

Security, authentication, Keystore, performance, testing, observability, CI/CD, publishing, Android-version compatibility, migration, code review, Automotive, NDK/JNI, KMP, architecture decision records, system-design case studies, and architect interviews.
