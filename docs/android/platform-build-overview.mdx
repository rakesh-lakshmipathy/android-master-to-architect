# Part II — Android platform and build system

<Admonition type="tip" title="What this part teaches">
An Android app is not just Kotlin code. The operating system starts processes, creates components, delivers IPC calls, manages memory, recreates UI, resolves resources, and installs an optimized APK or App Bundle produced by Gradle and Android build tools.
</Admonition>
