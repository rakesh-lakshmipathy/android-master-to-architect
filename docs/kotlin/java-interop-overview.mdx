# Java interoperability and gradual migration

<Admonition type="tip" title="Simple idea">
Kotlin and Java compile to JVM bytecode and can coexist in one Android module. The difficult parts are not calling methods; they are nullability, properties, default arguments, checked exceptions, generics, SAM interfaces, and maintaining a stable API for both languages.
</Admonition>
