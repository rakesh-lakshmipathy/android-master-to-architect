# Kotlin string manipulation - complete reference

This six-page reference groups the most useful Kotlin string APIs and common interview algorithms in one place. Use it for revision after learning the underlying ideas; do not memorize method names without understanding their behavior and failure cases.

## What it covers

- creation, properties, templates, multiline strings, and character access;
- searching, indexes, comparison, extraction, trimming, replacement, splitting, and joining;
- character predicates and collection-style string operations;
- numeric and collection conversions;
- mutable processing with `StringBuilder`;
- regular expressions;
- interview exercises such as palindrome, anagram, character frequency, rotation, and longest common prefix.

<Admonition type="tip" title="How to study with this reference">
Choose one group, predict the result of every example, run variations with empty strings and missing delimiters, and then implement one practical scenario without looking at the answer. The detailed website lessons explain the “why”; this PDF is the quick recall sheet.
</Admonition>
