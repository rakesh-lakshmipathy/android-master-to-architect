# Coroutines, structured concurrency, Flow, StateFlow, SharedFlow, and channels

<Admonition type="tip" title="Simple idea">
A coroutine is cancellable work that may suspend without blocking its thread. Structured concurrency gives that work an owner. Flow represents asynchronous values over time; StateFlow stores current state; SharedFlow broadcasts events/values; channels send values between coroutines.
</Admonition>
