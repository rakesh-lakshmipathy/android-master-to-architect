# Functions, lambdas, higher-order functions, inline functions, and reified types

This chapter is split into short pages. Read them in order the first time. Later, open only the page you need for revision.

<Admonition type="tip" title="Simple way to think about the chapter">
A function names reusable behavior. A lambda is behavior stored as a value. A higher-order function accepts or returns behavior. `inline` can remove some function-object and call overhead. `reified` lets an inline function use a generic type at runtime.
</Admonition>
