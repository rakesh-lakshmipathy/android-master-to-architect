# Types, variables, expressions, control flow, equality, and smart casts

This chapter is divided into short, focused screens. Read them in order because each page builds on facts established by the previous one.

<Admonition type="tip" title="Mental model">
A type describes the values an expression may produce. A variable names a value. Control flow selects an expression. Smart casts use facts proven by that flow to expose a more specific type safely.
</Admonition>

3. [Equality](./equality) — `==`, `===`, equality contracts, collections, Compose, and diffing.
4. [Type checks and smart casts](./smart-casts) — `is`, `!is`, `as`, `as?`, stability, and boundary validation.
