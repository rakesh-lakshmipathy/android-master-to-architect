# Types, variables, expressions, control flow, equality, and smart casts

This chapter is split into short pages. Read them in order the first time; later, use each page as a quick reference.

<Admonition type="tip" title="Simple way to think about it">
A type tells Kotlin what kind of value it is handling. A variable gives that value a name. Control flow decides which code runs. After a successful type check, a smart cast lets you use the value as the checked type without writing a manual cast.
</Admonition>
