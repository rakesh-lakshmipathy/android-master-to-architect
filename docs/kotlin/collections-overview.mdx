# Collections, sequences, generics, variance, extensions, delegates, and DSLs

<Admonition type="tip" title="Simple idea">
Collections store groups of values. Sequences process values lazily. Generics keep reusable APIs type-safe. Variance controls safe subtype relationships. Extensions, delegates, and DSLs improve how reusable behavior is expressed.
</Admonition>
